# FrameTrail hypervideos

FrameTrail keeps everything in JSON files: a `_data` folder, or one HTML page (a project file) that carries the same folder in a JSON data block. These references are FrameTrail's own documentation, at the version this plugin is built against:

- [DATA-MODEL.md](references/frametrail/DATA-MODEL.md): the files of a `_data` folder, bundles, items, time and space, identity and timestamps, legacy shapes, the checks beyond the schemas.
- [HTML-FORMAT.md](references/frametrail/HTML-FORMAT.md): the portable HTML format, and editing a project file in place.
- [TYPES.md](references/frametrail/TYPES.md): every type of overlay, annotation and library resource, what it is for and the attributes it takes.

Read what the task needs; do not load all three at once.
